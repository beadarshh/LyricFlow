# Media for the main README

| File | What it shows |
| --- | --- |
| `kinetic.gif` | Kinetic style floating over a desktop, words popping in on a colour block |
| `classic.gif` | Classic style, a line filling word by word with the next line dimmed below |
| `fullscreen.gif` | Full-screen Kinetic on a black background |
| `settings.png` | The Settings window |

These were rendered with LyricFlow's own `LyricsView` and `SettingsWindow` using original sample lyrics (not a real song) and a stepped clock, so they are deterministic and free of copyrighted lyrics. The desktop background and taskbar in the floating clips are a drawn stand-in.

To replace them with real screen recordings, keep the same file names. About 960 px wide at 15-20 fps keeps each GIF small enough for GitHub to render quickly.
